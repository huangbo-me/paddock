# PadDock 爱发电离线授权

用户已要求接入爱发电收费，确认 14 天完整试用和离线激活。商品尚未创建；不收集 API Token、不代开店或发布商品。本次交付实现并验证本地购买/授权流程和发码工具，真实付款必须待商品上线后验证。

## 范围

- 新增购买与激活页面、14 天试用、当前商业版本线（version 1）永久签名许可证。App 版本 0.2.0 内测属于此版本线。
- 购买 URL 在打包配置中指定，只允许 HTTPS afdian.com/afdian.net 的具体主页或商品路径；未配置时明确禁用购买，不跳到其他卖家或平台首页。
- 离线激活：Ed25519 签名，App 仅包含公钥。码包含 schema、product、majorVersion、licenseID、issuedAt；不包含用户信息、不限制台数、不支持远程吊销/退款自动撤销。许可证可被复制这一限制需明确。
- 开发者 CLI 创建私钥（权限 0600，忽略目录）和公钥配置，批量输出每行一个激活码供爱发电自动随机回复导入。禁止覆盖密钥或已有发码批次。私钥不进入 App/DMG/zip/git。
- 试用由用户点击开始；有效期恰好 14*24 小时。试用与授权保存在 Keychain，重置偏好不重置试用。读取失败显示错误，不默认为新试用。时钟回拨超过 5 分钟暂停普通试用授权，但已验签许可证仍可用。
- 付费门控只阻止新的自动连接、配对或开启新功能；从不主动断开会话或移除支持屏。断开、暂停、手动恢复、诊断始终可用。
- 无显示器恢复优先：已配对且已开启 headless，无法确认还有独立可用显示器时继续恢复连接，即使试用过期，UI 明示恢复保护；这是刻意的安全豁免，不是严格 DRM。
- 屏幕证据保守取在线内置屏幕；外接屏可能是虚拟设备或模拟插头，不能据此阻止恢复。Mac mini 已配置的无显示器恢复因此允许到期后继续工作。
- 后台钥匙串读写不弹权限请求；用户点击重新读取、开始试用或激活时允许系统授权交互，作用域结束后立即恢复非交互访问。
- 不修改 /Applications 中正在工作的 App；交付独立 0.2.0 包，当前 0.1.0 保持运行。

## 模块

Core/Commerce.swift: 签名验证、试用状态、购买URL校验、付费动作判定。
App/CommerceStore.swift: Keychain、发布状态、开始试用和激活、购买链接；无网络API调用。
App/CommerceView.swift: 中文购买/激活界面；Controller/Views/Main 集成。
Tools/LicenseTool.swift: keygen/issue/verify 子命令，私钥仅在独立工具进程中使用。
Resources/Commerce.json: 公钥、可空商品URL、commercialMajor=1。
Tests: 签名篡改、错产品/版本、超大输入、试用边界/时钟回拨、坏存储、入口约束、屏幕安全、CLI发行闭环。
